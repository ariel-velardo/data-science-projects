Bonilha EA et al. Coverage, completeness and reliability of the data in the Information System on Live Births in public maternity wards in the municipality in São Paulo, Brazil, 2011. Epidemiol Serv Saude. 2018;27:e201712811.

[Fonte consultada](https://www.scielo.br/j/ress/a/Vqsdk5khwLbWBNDc9RZvqPb/). Síntese limitada ao resumo/trechos públicos e mapa já auditado; PDF não obtido nesta sessão.

| Item | Leitura |
| --- | --- |
| Pergunta | Confiabilidade dos campos do SINASC. |
| População | 5.785 registros de quatro maternidades públicas; São Paulo, 2011. |
| Dados | SINASC comparado a estudo de campo. |
| Método | Cobertura, completude e concordância kappa. |
| Principais resultados | Boa concordância de peso e gravidez; concordância menor para consultas e perdas fetais. |
| Limitações | Quatro hospitais e período local; não valida nacionalmente os dados de 2024. |
| Relação com o projeto | Justificar auditoria e cautela com história reprodutiva e assistência. |

Não transportar efeitos ou garantias deste artigo automaticamente para o SINASC 2024.
