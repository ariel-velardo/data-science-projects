# Artigos citados no Pacote de Redação — Etapa 1

Índice das 19 referências de `referencias.bib` (projeto Overleaf). Os PDFs vieram apenas de fontes
de acesso aberto: periódico, SciELO, NBER, arXiv e repositório institucional. Em cada um, título e
autores foram conferidos na primeira página. Quando o download automático foi bloqueado ou o texto
não é aberto, registra-se só o link oficial; nenhum bloqueio foi contornado.

gratuito no PubMed Central ou no periódico, que pode ser baixado pelo navegador.
