# Dicionário analítico SINASC 2024

62 colunas, uma linha por campo original, na ordem do schema auditado. Ausente é nulo/vazio segundo a auditoria da Fase 0. Ignorado conta apenas códigos documentalmente confirmados; quando não há código confirmado, o percentual combinado é desconhecido, não zero. Zero estrutural e “não se aplica” não são ignorados. Denominador: toda a base bruta. Os exemplos são valores frequentes independentes por coluna, nunca registros individuais.

OPORT_DN: **NÃO_CONFIRMANDO_DOCUMENTALMENTE**. O layout disponível termina em 2019; não é um layout específico de 2024. Domínios numéricos e códigos não enumerados no layout não são inventados. PARIDADE e perdas seguem as regras operacionais do contrato, distintas da comprovação documental de todos os códigos.
